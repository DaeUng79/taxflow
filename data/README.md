# 로컬 임시 데이터

처음 `python3 -m backend`를 실행하면 이 폴더에 `taxflow.sqlite3`가 생성되고 가상 예시 한 건이 자동으로 들어갑니다. 이후 실행에서는 기존 DB를 유지합니다.

이 폴더의 DB 파일과 백업은 Git에서 제외합니다. SQLite 기본 파일은 암호화되지 않습니다. 실제 납세자 정보는 저장하지 마세요.

미션별 학습 확인과 완료 표시는 별도 파일 `mission_progress.sqlite3`에 저장됩니다. 서버를 다시 시작하거나 화면을 새로고침해도 유지되며, 수업 안내의 학습 표시 초기화는 이 기록만 삭제합니다. 상담 기록과 계약서 자료는 `taxflow.sqlite3`에 별도로 남습니다.
